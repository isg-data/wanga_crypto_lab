# 🧠 Wanga Crypto Lab

**Wanga Crypto Lab** is an open playground for experimenting with cryptocurrency prediction and analysis.  
The goal is to explore different ideas — from basic heuristics to advanced ML models — to forecast crypto market movements.  
Inspired by the legendary foresight of **Baba Wanga**, this repo combines data-driven methods with a curious spirit of exploration. 🪄

---

## 🧩 Current Experiment: Crypto Price Direction Classification

This script demonstrates how to gather cryptocurrency data, perform exploratory analysis, engineer features, and build models that classify whether a crypto’s price will **go up** or **not**.

### What’s Inside

- **Data fetching** for crypto prices  
- **Exploratory Data Analysis (EDA)**  
- **Feature Engineering** for model-ready inputs  
- **Classification Models:**
  - Logistic Regression  
  - Decision Tree  
  - Random Forest  
  - XGBoost  
  - Feedforward Neural Network (FFNN)
